# Web Proxy - מדריך שימוש

## תיאור
אתר proxy שמאפשר לך לגלוש באתרים אחרים דרכו ולעקוף חסימות.

## איך להשתמש?

1. **פתח את הקובץ `index.html`** בדפדפן (Chrome, Firefox, Edge, וכו')

2. **הכנס כתובת אתר** בשדה הטקסט
   - לדוגמה: `https://www.google.com`
   - אם לא תכניס `https://` זה יתוסף אוטומטית

3. **לחץ על "גלוש"** או לחץ Enter

4. **השתמש בכפתורים**:
   - ◀ אחורה - חזרה לעמוד הקודם
   - קדימה ▶ - קדימה לעמוד הבא
   - 🔄 רענן - רענון העמוד הנוכחי
   - 🏠 בית - חזרה למסך הבית

## תכונות מיוחדות

✅ **עוקף proxy** - משתמש בשירותי proxy חיצוניים לעקיפת חסימות
✅ **תומך במובייל** - מתאים לגלישה בטלפון
✅ **היסטוריה** - מעקב אחרי העמודים שביקרת
✅ **ממשק בעברית** - קל לשימוש

## שירותי Proxy בשימוש

הקוד משתמש בשירות `AllOrigins` כברירת מחדל. אם זה לא עובד, ניתן לשנות בקובץ `script.js` לאחד מהשירותים הבאים:

```javascript
// AllOrigins (ברירת מחדל)
return `https://api.allorigins.win/raw?url=${encodeURIComponent(url)}`;

// אפשרויות נוספות:
return `https://corsproxy.io/?${encodeURIComponent(url)}`;
return `https://api.codetabs.com/v1/proxy?quest=${encodeURIComponent(url)}`;
return `https://thingproxy.freeboard.io/fetch/${encodeURIComponent(url)}`;
```

## הגבלות

⚠️ **חשוב לדעת:**
- לא כל האתרים ניתנים לטעינה דרך proxy (בגלל אבטחה)
- אתרים עם הגנות מתקדמות (כמו בנקים) עלולים לא לעבוד
- מהירות הגלישה תלויה בשירות ה-proxy
- יש אתרים שחוסמים טעינה ב-iframe

## פתרון בעיות

**האתר לא נטען?**
1. בדוק שהכתובת תקינה
2. נסה להוסיף `https://` בהתחלה
3. נסה אתר אחר
4. רענן את העמוד

**האתר נטען אבל לא עובד כמו שצריך?**
- חלק מהאתרים לא יעבדו באופן מלא דרך proxy
- נסה לשנות את שירות ה-proxy בקובץ `script.js`
